## 🌐 Overview
https://sentinel-global-emergency-monitor-24825561634.us-west1.run.app/

The Sentinel Global Emergency Monitor is a state-of-the-art intelligence dashboard designed to track, categorize, and analyze critical global crises in real-time. By monitoring all global aspects—from military movements and civil unrest to natural disasters and health emergencies—Sentinel provides users with a unified "single pane of glass" view of world stability.

---

## ✨ Key Features

### 🔴 Global Threat Level (DEFCON)
A prominent visual indicator communicating the current state of global readiness. The system dynamically updates based on the cumulative severity of active global incidents.

### 🕵️ WatchList Threat Identifier
A specialized analytical layer that identifies and monitors key global leaders. It provides an estimated threat level for specific individuals based on rhetoric, policy shifts, and regional stability factors.

### 📡 Active Emergency Feed
A real-time, color-coded stream of global incidents categorized by:
* Defense & Military
* Law Enforcement
* Civil & Political Unrest
* Natural Disasters
* Global Health

### 🗺️ Geospatial Risk Mapping
An interactive mapping interface that pinpoints the exact coordinates of active emergencies, allowing for immediate spatial analysis of crisis clusters.

### 📝 Syndicate Brief
An AI-synthesized intelligence summary that connects the dots between disparate global events, providing a narrative overview of current global risks.

## 🛠️ Technical Stack
* AI Engine: Google Gemini (via Google AI Studio)
* Deployment: Google Cloud Run (Serverless)
* Environment: Python/Flask | Node.js
* Data Handling: GDELT, USGS, News APIs
